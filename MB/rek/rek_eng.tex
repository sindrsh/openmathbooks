	\section{Mathematical Operations}
	If we combine two or more numbers to create a new number, we perform a \outl{mathematical operation}\index{mathematical operation}. \outl{Addition}, \outl{subtraction}, \outl{multiplication}, and \outl{division} are our fundamental mathematical operations, and we call them the four basic \outl{arithmetic operations}\index{arithmetic operation}. When we use these operations, we create \outl{calculations}\index{calculation}. The value we get from performing a mathematical operation is usually called the \outl{answer} to the calculation.
	
	\section{Addition \label{Addisjon} \index{addition}}
	\subsection*{Addition with Quantities: Adding}
	When we have a quantity and want to add more, we use the \outl{plus sign} \\
	%id{plussym}
	\sym{$ + $}
	%\id
	\!\!. If we have 2 and want to add 3, we write
	%id{2plus3}
	\[ 2+3=5 \]
	%\id
	\fig{plusm1}
	The order in which we add the numbers does not matter; starting with 2 and then adding 3 is the same as starting with 3 and then adding 2:
	%id{3plus2}
	\[ 3+2=5 \]
	%\id
	\fig{plusm1a}
	\spr{
		An addition problem consists of two or more \outl{terms}\index{term} and one \outl{sum}\index{sum}. In the addition problem
		%id{2plus3}
		\[ 2+3=5 \]
		%\id
		both 2 and 3 are terms, while 5 is the sum.\vsk
		
		Common ways to say
		%id{2plus3inline}
		$ 2+3 $
		%\id
		are
		\begin{itemize}
			\item "2 plus 3"
			\item "2 added to 3"
			\item "2 and 3 added together"
		\end{itemize}
		Adding numbers is also called \outl{summing}\index{summing}.
	} \regv
	\newpage
	\reg[Addition is Commutative \label{adkom}]{
		The sum is the same regardless of the order of the terms.
	}
	\eks{ \vsb
		%id{pluscommutative}
		\alg{
			2+5 &= 7 =5+2  \vn
			6+3 &=9=3+6
		}
		%\id
	}
	
	\subsection*{Addition on the Number Line: Moving to the Right}
	On a number line, addition with positive numbers means moving \textsl{to the right}:\regv
	\eks[1]{ \vs
		%id{2plus7}
		\[ 2+7=9 \]
		%\id
		\fig{plus2}
	}
	\eks[2]{ \vs
		%id{4plus11}
		\[ 4+11=15 \]
		%\id
		\fig{plus3}
	}
	\info{A New Meaning of
		%id{symeq}
		\sym{$\bm=$}
		%\id
	}{
		%id{plussym}
		\sym{$ + $}
		%\id
		gives us the ability to express numbers in many different ways. For example,
		%id{5eq2plus3}
		$ {5=2+3} $
		%\id
		and
		%id{5eq1plus4}
		$ {5=1+4} $
		%\id
		\!. In this context,
		%id{symeq}
		\sym{$ = $}
		%\id
		means "has the same value as." This also applies to subtraction, multiplication, and division, which we will look at in the next three sections.
	}
	
	\section{Subtraction \label{Subtraksjon}} \index{subtraction}
	\subsection*{Subtraction with Quantities: Taking Away}
	When we have a quantity and remove part of it, we use the \\\outl{minus sign} \sym{$ - $}. If we have 5 and want to remove 3, we write
	%id{5min3}
	\[ 5-{\color{red} 3}=2 \]
	%\id
	\fig{min1c}
	
	\spr{
		A subtraction problem consists of two or more \outl{terms}\index{term} and one\\ \outl{difference}\index{difference}. In the subtraction problem
		%id{5min3lang}
		\[  5-3=2 \] 
		%\id
		both 5 and 3 are terms, while 2 is the difference. \vsk
		
		Common ways to say
		%id{5min3inline}
		$ 5-3 $
		%\id
		are
		\begin{itemize}
			\item "5 minus 3" \\
			\item "5 subtracted by 3"
			\item "3 taken from 5"
			\item "3 subtracted from 5"
		\end{itemize}
	} \vsk
	
	\info{A New Interpretation of 0}{
		In chapter \refkap{Talavare}, we mentioned that 0 can be interpreted as "nothing." Subtraction gives us the ability to express 0 using other numbers. For example,
		%id{7min7}
		$ {7-7=0} $ 
		%\id
		and
		%id{19min19}
		$ {19-19=0} $
		%\id
		\!\!.
	} \vsk
	
	\begin{comment}
		\info{Subtraction is \textsl{not} Commutative}{
			$ 5-3 $ is not equal\footnote{What $ 3-5 $ is will be discussed in \hrs{Negtal}{chapter}} $ 3-5 $. If all arithmetic operations were commutative, the order of operations would not matter.
		}
	\end{comment}

	In \hrs{Addisjon}{section}, we saw that
	%id{plussym}
	\sym{$ + $}

	%id{minsym}
	\sym{$ - $}
	%\id
	we do the opposite; we move \textsl{to the \\left}\!
	%id{arrow}
	\footnote{In figures with number lines, red arrows indicate that you start at the arrowhead and move to the other end.}
	:\regv

		In \textsl{Example 1} and \textsl{Example 2} below, we move in the opposite direction of the arrow. This means we start at the arrowhead and move to the end. This may seem a bit strange at first, but it will be useful, especially in \refkap{Negtal}, to think this way.
	} 
	\eks[1]{ \vs
		%id{6min4}
		\[ 6-4=2 \]
		%\id
		\fig{mint}
	}
	\eks[2]{ \vs
		%id{12min5}
		\[ 12-7=5 \]
		%\id

	\newpage
	\info{Inverse Operations}{
		The figures showing addition and subtraction on the number line illustrate why we say that addition and subtraction are \outl{inverse\\ operations}\index{inverse operation}. \vsk
		
		For example: Since $2+4=6$, we know that $6-4=2$ and $6-2=4$.
	}
	
	\info{Canceling Terms}{
		If we have an expression where numbers with the same value are added as many times as they are subtracted, we say they \outl{cancel} each other out. In the expression
		%id{mincncla}
		\[ 4+3-4+4+7-4+1 \]
		%\id
		we have as many 4s added as we have 4s subtracted. The total sum and difference of the 4s is equal to 0. Thus, we can simplify our expression to
		%id{mincnclb}
		\[ 3+7+1 \]
		%\id
		\textsl{Note!} In \refkap{Brok}, the word \textit{canceling} will have a different meaning.
	}
	
	\section{Multiplication \label{Gonging} } \index{multiplication}\index{multiplication}
	
	\subsection*{Multiplication with Whole Numbers: Introductory Definition}
	When we add the same numbers together, we can use the \outl{multiplication sign}
	%id{timessym}
	\sym{$ \cdot $}
	%\id
	to write our calculations more concisely: \regv
	\eks[]{\vsb
		%id{firsttimes}
		\alg{
			4+4+4 &= 4\cdot 3 \vn
			8+8 &=8\cdot 2 \vn
			1+1+1+1+1&= 1\cdot5
		}
		%\id
	} \regv
	\spr{
		A multiplication problem consists of two or more \outl{factors}\index{factor} and one \\ \outl{product}\index{product}. In the multiplication problem
		%id{4times12}
		\[ {4\cdot 3=12} \]
		%\id
		4 and 3 are factors, while 12 is the product. \vsk
		
		Common ways to say
		%id{4times12inline}
		$ 4\cdot3 $
		%\id
		are
		\begin{itemize}
			\item "4 times 3"  \\
			\item "4 multiplied by 3"\\
			\item "4 times 3"
		\end{itemize}
		
		Many websites and books in English use the symbol
		%id{timesx}
		\sym{$ \times $}
		%\id
		as the multiplication sign. In most programming languages, the symbol
		%id{times*}
		\sym{*}
		%\id
		\! is used.
	}

	We can also use the number line to solve multiplication problems. For example, we can find what

	%id{2times4lang}

	\subsection*{Final Definition of Multiplication with Positive Whole Numbers}
	It might seem most natural to interpret "2 times 3" as "3, 2 times." So,
	%id{2times3lang}
	\[ \text{''2 times 3''}=3+3 \]
	%\id
	%id{amounttimesref}
	On page \pageref{gangmengd},
	%\id
	we presented
	%id{2times3}
	$ 2\cdot3 $
	%\id
	\!\!, i.e., "2 times 3," as
	%id{2plus2plus2}
	$ {2+2+2} $
	%\id
	\!\!. With this interpretation,
	%id{3plus3}
	$ {3+3} $
	%\id
	corresponds to
	%id{3times2}
	$ {3\cdot2} $
	%\id
	\!\!, but since multiplication is a commutative operation (\rref{gangkom}), one interpretation does not exclude the other;
	%id{2times3eq2plus2plus2}
	$ {2\cdot3 =2+2+2} $
	%\id
	and
	%id{2times3eq3plus3}
	$ {2\cdot3=3+3} $
	%\id
	are two expressions with the same value. Thus, we can also write $2\cdot3=3+3$ and $3\cdot2=2+2+2$.\regv
	
	\reg[Multiplication as Repeated Addition \label{ganggjad2}]{
		Multiplication with a positive whole number can be expressed as repeated addition.
	}
	\eks[1]{\vsb
		%id{repeatedaddition}
		\alg{
			4+4+4 &= 4\cdot 3=3+3+3+3 \vn
			8+8 &=8\cdot 2=2+2+2+2+2+2+2 \vn
			1+1+1+1+1&= 1\cdot5 =5
		}
		%\id
	}
	\info{Note}{
		The fact that multiplication with positive whole numbers can be expressed as repeated addition does not exclude other expressions. It is not wrong to write that
		%id{2times3alt}
		$ {2\cdot 3=1+5} $
		%\id
		\!\!.
	}
	
	\section{Division \label{Divisjon}} \index{division}\index{division}
	%id{divsym}
	\sym{:}
	%\id
	is the \outl{division sign}.
	Division has three different meanings, shown here with
	%id{12div3}
	$ 12:3 $
	%\id
	\!\!:\regv
	
	\reg[The Three Meanings of Division]{ \vs
		%id{divinterpret}
		\begin{itemize}
			\item \textbf{Equal Distribution of Quantities} \\
			$ 12:3 = \text{''The number in each group when 12 is divided into }$\\
			\hspace{1.6cm}3 equal large groups ''
			\item \textbf{Number of Times One Number Fits into Another} \\
			$ 12:3=\text{''How many times 3 fits into 12''} $
			\item \textbf{Inverse Operation of Multiplication}\\
			$ 12:3=\text{''The number you multiply 3 by to get 12''} $
		\end{itemize}
		%\id
	} \regv
	
	\spr{ \label{sprakdiv}
		A division problem consists of a \outl{dividend}\index{dividend}, a \outl{divisor}\index{divisor}, and a\\ \outl{quotient}\index{quotient}.
		In the division problem
		%id{12div3display}
		\[  {12:3=4} \]
		%\id
		12 is the dividend, 3 is the divisor, and 4 is the quotient.\vsk
		
		Common ways to pronounce
		%id{12div3}
		$ 12:3 $
		%\id
		are
		\begin{itemize}
			\item "12 divided by 3"
			\item "12 divided into 3"
			\item "12 over 3"
		\end{itemize}
		In some contexts,
		%id{12div3}
		$ {12:3} $
		%\id
		is called the "\outl{ratio}\index{ratio} between 12 and 3." In this case, 4 is the \outl{ratio value}\index{ratio value}. \vsk
		
		Often,
		%id{slash}
		\sym{$ / $}
		%\id
		is used instead of
		%id{divsym}
		\sym{$:$}
		%\id
		\!\!, especially in programming languages.
	}
	\newpage
	\subsection*{Equal Distribution of Quantities}
	The calculation
	%id{12div3}
	$ {12:3} $
	%\id
	tells us that we should distribute 12 into 3 equal groups:
	\fig{del1}
	We see that each group contains 4 squares, which means that
	%id{12div3display}
	\[ 12:3=4 \]
	%\id
	
	\subsection*{Number of Times One Number Fits into Another}
	\fig{del2}
	3 fits 4 times into 12, so
	%id{12div3eq4}
	$ 12:3=4 $
	%\id
	\!\!.
	
	\subsection*{Inverse Operation of Multiplication}
	We have seen that if we divide 12 into 3 equal groups, we get 4 in each group. So,
	%id{12div3eq4}
	$ 12:3=4$
	%\id
	\!\!. If we add these groups together again, we naturally get 12:
	\fig{del1b}
	But this is the same as multiplying 4 by 3. So;
	if we know that
	%id{4times3eq12}
	$ {4\cdot 3=12} $
	%\id
	\!\!, then we also know that
	%id{12div3eq4}
	$ {12:3=4} $
	\!\!. Additionally, we then know that
	%id{12div4eq3}
	$ {12:4=3} $
	%\id
	\!\!.
	\fig{del1a}

			18:6= 3\vn
			18:3=6
		}
		%\id
	}
