\subsection*{Problem: Bottema's theorem}

The red and the green quadrilateral are both squares. $F$ is the midpoint of $DE$. Let $\textbf{v}=\vv{AC}$ and $\textbf{u}=\vv{CB}$. Given a vector $\textbf{w}$, we define $\textbf{w}_p$ as the vector perpendicular to $\textbf{w}$, pointing to the left with respect to the direction of $\textbf{w}$, and with equal length as $\textbf{w}$.\os
\begin{enumerate}[label=\alph*)]
	\item Find the coordinates of $F$ expressed in terms of $\textbf{u}$, $\textbf{v}$, $\textbf{u}_p$, and $\textbf{v}_p$.
	\item Describe the possible displacement of $F$ if $C$ is shifted in an arbitrary direction. (It is sufficient to consider the case where $C$ is above $AB$).
\end{enumerate}
\fig{opgvekbottema}

\subsection*{Solution}

\fig{opgvekbottema_lf}

We introduce a coordinate system with the origin at $A$. Then $D=\textbf{v}_p$. Furthermore, $E=\textbf{u}+\textbf{v}+\textbf{u}_p$. Furthermore, $\vv{DE}=-\textbf{v}_p+\textbf{v}+\textbf{u}+\textbf{u}_p$. Thus,
\[ F = D+\frac{1}{2}\vv{DE}=\frac{1}{2}(\textbf{v}_p+\textbf{v}+\textbf{u}+\textbf{u}_p)=\frac{1}{2}(\textbf{u}+\textbf{v}+\textbf{u}_p+\textbf{v}_p) \]

$\textbf{u}+\textbf{v}$ and $\textbf{u}_p+\textbf{v}_p$ are orthogonal and have the same length. As long as $\textbf{u}+\textbf{v}$ does not change, $F$ will not be displaced. A displacement of $C$ does not change $\textbf{u}+\textbf{v}$, and thus the position of $F$ is independent of the position of $C$.

\textbf{Problem: van Aubel's theorem} \\
The colored quadrilaterals are squares. $E$, $F$, $G$, and $H$ are the respective midpoints of the squares. Show that $EG = FH$ and $\vv{EG} \perp \vv{FH}$.
\fig{opgvekvanbl}

\textbf{Answer}
\fig{opgvekvanbl_lf}
We introduce a coordinate system with the origin at $A$, and set $\vv{DA} = 2\textbf{v}$, $\vv{AB} = 2\textbf{u}$, and $\vv{BC} = 2\textbf{w}$ (in the figure, $\textbf{s} = \textbf{u} + \textbf{v} + \textbf{w}$). Then,
\begin{align*}
	E &= -\textbf{v} - \textbf{v}_p \\
	F &= \textbf{u} - \textbf{u}_p \\
	G &= 2\textbf{u} + \textbf{w} - \textbf{w}_p \\
	H &= \textbf{u} + \textbf{w} - \textbf{v} + \textbf{u}_p + \textbf{v}_p + \textbf{w}_p
\end{align*}
Thus,
\begin{align*}
	\vv{EG} &= 2\textbf{u} + \textbf{w} - \textbf{w}_p + \textbf{v} + \textbf{v}_p = 2\textbf{u} + \textbf{w} + \textbf{v} + \textbf{v}_p - \textbf{w}_p \\
	\vv{FH} &= \textbf{w} - \textbf{v} + 2\textbf{u}_p + \textbf{v}_p + \textbf{w}_p
\end{align*}
We have
\[
\vv{FH}_p = \textbf{w}_p - \textbf{v}_p - 2\textbf{u} - \textbf{v} - \textbf{w} = -\vv{EG}
\]
This means that $\vv{FH}$ and $\vv{EG}$ are orthogonal. Furthermore,
\[ FH = |\vv{FH}_p| = |-\vv{EG}| = EG \]

\subsubsection*{The Quatratic Function}

\subsubsection*{Problem 1}
Given the function ${f(x) = a x^2 + b x + c}$. Show that the graph of $f$ is symmetric about the line ${x = -\frac{b}{2a}}$.

\subsubsection*{Answer}
For the graph of $f$ to be symmetric about the line ${x = -\frac{b}{2a}}$, for any number $k$, we must have
\begin{equation}\label{opggeokvadsymeq}
	f\left(k - \frac{b}{2a}\right) = f\left(-k - \frac{b}{2a}\right)
\end{equation}

For a number $d$, we have
\[
d - \frac{b}{2a} = \frac{2ad - b}{2a}
\]

Furthermore,
\begin{align*}
	f\left(d - \frac{b}{2a}\right) &= a\left(\frac{2ad - b}{2a}\right)^2 + b\left(\frac{2ad - b}{2a}\right) + c \\
	&= \frac{4a^2d^2 - 4abd + b^2}{4a} + \frac{2abd - b^2}{2a} + c \\
	&= \frac{4a^2d^2 - b^2}{4a} + c
\end{align*}

This means that regardless of whether $d = k$ or $d = -k$, the expression above will be the same, and thus \eqref{opggeokvadsymeq} holds.

\subsection*{Problem 2}
Given the function $f(x) = ax^2 + bx + c$. In Problem 1, we showed that $f$ is symmetric about the line $x = \frac{-b}{2a}$. Furthermore, it can be shown that for all numbers $k$,
\[
f\left(\pm k - \frac{b}{2a}\right) = \frac{4a^2k^2 - b^2}{4a} + c
\]
Use this to derive the \textit{abc}-formula.

\subsection*{Answer}
If \( f(x) = ax^2 + bx + c = 0 \), then for a number \( k \), we have
\[
f\left(\pm k - \frac{b}{2a}\right) = \frac{4a^2k^2 - b^2}{4a} + c = 0.
\]
Solving this equation for \( k \), we obtain
\[
k = \pm \frac{\sqrt{b^2 - 4ac}}{2a}.
\]
This means that
\[
f\left(\pm \frac{\sqrt{b^2 - 4ac}}{2a} - \frac{b}{2a}\right) = 0.
\]

\subsection*{Problem 3}
Given the function \( f(x) = ax^2 + bx + c \).

\abc{
	\item Find an expression for the extremal value.
	\item Explain why
	\begin{itemize}
		\item a change in \( c \) will result in a vertical shift of the graph of \( f \).
		\item a change in \( a \) or \( b \) will result in both a horizontal and a vertical shift of the graph of \( f \).
	\end{itemize}
}

\subsection*{Answer}
\textit{In this solution, we assume the function has a minimum point. The case where it has a maximum point is entirely analogous.}

\abc{
	\item Since \( x = -\frac{b}{2a} \) is the extremal point of \( f \), the extremal value \( f_e \) is given by
	\[
	f_\text{e} = f\left(-\frac{b}{2a}\right) = a\left(-\frac{b}{2a}\right)^2 + b\left(-\frac{b}{2a}\right) + c = -\frac{b^2}{4a} + c
	\]
	
	\item Since the extremal point is expressed in terms of \( a \) and \( b \), a change in \( c \) will not affect the horizontal position of the minimum point. However, \( c \) is part of the expression for \( f_e \), so a change in \( c \) will alter the vertical position of the minimum point.
	
	Both \( a \) and \( b \) are part of the expressions for the extremal point and \( f_e \). Thus, a change in \( a \) or \( b \) will shift the minimum point both horizontally and vertically.
	
	A shift in the minimum point necessarily corresponds to a shift in the graph of \( f \).
}

\subsection*{Problem 4}
Given the function \( f(x) = ax^2 + bx + c \), where\footnote{The case where \( a < 0 \) is entirely analogous.} \( a > 0 \).
To describe the shape of the graph of \( f \), we do the following\footnote{The case where \( f \) has a maximum point instead of a minimum point is entirely identical.}:

\begin{itemize}
	\item Let \( g(x) \) be the function that describes the difference between \( f(x) \) and the minimum value of \( f \).
	\item Let \( h(g) \) be the horizontal distance between \( g(x) \) and the line \( x = -\frac{b}{2a} \).
\end{itemize}

If two quadratic functions have identical expressions for \( h(g) \), we can say that the functions have the same shape.

\abc{
	\item Show that
\[
h(g) = \sqrt{\frac{g}{a}}
\]

\item Refer back to Problem 3, and create a summary of how a change in \( a \), \( b \), or \( c \) might affect
\begin{itemize}
	\item the horizontal shift of the graph,
	\item the vertical shift of the graph,
	\item the shape of the graph.
\end{itemize}
}

\fig{opginvsym}

\newpage
\subsection*{Answer}
\abc{
	\item In Problem 3, we found that the extremal value \( f_\text{e} \) of \( f \) is
	\[
	f_\text{e} = -\frac{b^2}{4a} + c
	\]
	Therefore,
	\[
	g(x) = f(x) - f_\text{e} = ax^2 + bx + c - \left(-\frac{b^2}{4a} + c\right) = ax^2 + bx + \frac{b^2}{4a}
	\]
	Solving this equation for \( x \), we get from the quadratic formula:
	\[
	x = \frac{-b \pm \sqrt{b^2 - 4a\left(\frac{b^2}{4a} - g\right)}}{2a} = \frac{-b \pm 2\sqrt{ag}}{2a}
	\]
	Let \( p(g) = x \) be the inverse function of \( g \) for \( x \in [-\infty, -\frac{b}{2a}] \). Then,
	\[
	p(g) = \frac{-b - 2\sqrt{ag}}{2a}
	\]
	Furthermore,
	\[
	h(g) = p(g) - \left(-\frac{b}{2a}\right) = \sqrt{\frac{g}{a}}
	\]
	
	\item A change in \( c \) vertically shifts the graph but does not change its shape.
	
	A change in \( b \) shifts the graph both horizontally and vertically but does not change its shape.
	
	A change in \( a \) shifts the graph both horizontally and vertically and changes the shape of the graph.
}

\subsection*{Problem 5}
Given the function \( f(x) = a x^2 + b x + c \), and the points \( {A = (p, f(p))} \) and \( B = (q, f(q)) \). The tangent to \( f \) at the point \( C = (t, f(t)) \) is parallel to the segment \( AB \).

\abc{
	\item Show that \( t = \frac{1}{2}(p + q) \).
	\item Show that the area of \( \triangle ABC \) is \( \frac{1}{8}(q - p)^3 \).
}
\fig{opgderarchi}
\newpage
\subsection*{Answer}
\fig{opgderarchi_lf}
\abc{
	\item We have
	\[
	A = (p, a p^2 + b p + c) \qquad \text{and} \qquad B = (q, a q^2 + b q + c)
	\]
	Let \( g(x) \) be the function describing the line through \( AB \). Then,
	\begin{align*}
		g'(x) &= \frac{f(q) - f(p)}{q - p} \\
		&= \frac{a q^2 + b q + c - (a p^2 + b p + c)}{q - p} \\
		&= \frac{a(q^2 - p^2) + b(q - p)}{q - p} \\
		&= \frac{a(q + p)(q - p) + b(q - p)}{q - p} \\
		&= a(q + p) + b
	\end{align*}
	Let \( C = (t, f(t)) \). Then we have
	\begin{align*}
		f'(t) &= a(q + p) + b \\
		2a t + b &= a(q + p) + b \\
		t &= \frac{1}{2}(q + p)
	\end{align*}
	
	\item Let \( D \) be the midpoint of \( AB \). Then,
	\[
	D = \left(t, \frac{1}{2}(f(q) + f(p))\right)
	\]
	Furthermore,
	\begin{align*}
		DC &= \frac{1}{2}\left(f(q) + f(p)\right) - f(t) \\
		&= \frac{1}{2}\left(a(p^2 + q^2) + b(p + q) + 2c\right) - a\left(\frac{1}{2}(p + q)\right)^2 + b\left(\frac{1}{2}(p + q)\right) + c \\
		&= \frac{a}{2}(p^2 + q^2) - \frac{a}{4}(p + q)^2 \\
		&= \frac{a}{4}(2p^2 + 2q^2 - p^2 - q^2 - 2pq) \\
		&= \frac{a}{4}(q - p)^2
	\end{align*}
	We place \( E \) and \( F \) such that \( \square AEFB \) is a parallelogram. With \( AE \) as the base, the height of \( \square AEFB \) is \( q - p \). Since \( AE = DC \), we have
	\[
	A_{\triangle ABC} = \frac{1}{2} A_{\square AEFB} = \frac{1}{2} \cdot \frac{a}{4}(q - p)^2 (q - p) = \frac{a}{8}(q - p)^3
	\]
}

Since only $a$ affects the shape of $f$, $a$ must also appear in the expression for $I$, but not $b$ and $c$.
	
	\item Let $g(x)$ be the function describing the line through $AB$. Then
	\begin{align*}
		g(x) &= (a(p+q)+b)(x-p) + f(p) \\
		&= (a(p+q)+b)x - (a(p+q)+b)p + ap^2 + bp + c \\
		&= (a(p+q)+b)x - apq + c
	\end{align*}
	We have that
	\[
	g - f = ax(p+q) - apq - ax^2
	\]
	Therefore,
	\begin{align*}
		I &= \int_{p}^{q} (g - f) \, dx \\
		&= \left[\frac{ax^2}{2}(p+q) - apqx - \frac{1}{3}ax^3\right]_p^q \\
		&= \frac{aq^2}{2}(p+q) - apq^2 - \frac{1}{3}aq^3 - \left(\frac{ap^2}{2}(p+q) - ap^2q - \frac{1}{3}ap^3\right) \\
		&= \frac{a}{2}(p+q)(q^2 - p^2) - apq(q - p) - \frac{a}{3}(q^3 - p^3) \\
		&= \frac{a}{2}(q-p)((p+q)^2 - 2pq) - \frac{a}{3}(q^3 - p^3) \\
		&= \frac{a}{2}(q-p)(p^2 + q^2) - \frac{a}{3}(q^3 - p^3) \\
		&= \frac{a}{2}(q-p)(p^2 + q^2) - \frac{a}{3}(q-p)(p^2 + q^2 + pq) \\
		&= \frac{a}{6}(q-p)(3p^2 + q^2 - 2p^2 - 2q^2 - 2pq) \\
		&= \frac{a}{6}(q-p)^3
	\end{align*}
	
	\item Since $I = \frac{a}{6}(q-p)^3$ and $A_{\triangle ABC} = \frac{a}{8}(q-p)^3$, we have
	\[
	\frac{I}{A_{\triangle ABC}} = \frac{4}{3}
	\]
	
	\item We have that
	\begin{align*}
		A_{\text{blue area}} + A_{\triangle ABC} &= \frac{4}{3}A_{\triangle ABC} \\
		\frac{A_{\triangle ABC}}{A_{\text{blue area}}} &= 3
	\end{align*}
}
